# StockMaster
## Descripción
StockMaster es un prototipo web para la gestión inteligente de inventarios en pequeñas y medianas empresas con múltiples sucursales. Su objetivo es centralizar la información del inventario, facilitar el control de existencias y apoyar la toma de decisiones mediante herramientas de análisis y predicción de demanda.

## Objetivo
Desarrollar un prototipo web que demuestre la aplicación de conceptos de Software Distribuido, Arquitectura Orientada a Servicios, servicios RESTful, DevOps y gestión de proyectos, utilizando GitHub como herramienta de trabajo colaborativo.
